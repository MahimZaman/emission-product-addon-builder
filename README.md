# Emission Product Addon Builder

A WordPress plugin scaffold for WooCommerce product add-ons with custom pricing.

## Installation and use

1. Place the `emission-product-addon-builder` folder in `wp-content/plugins/`.
2. Activate Emission Product Addon Builder in the WordPress Plugins screen.

The current version contains the plugin header and empty implementation files. Activating it registers no product fields or pricing rules.
